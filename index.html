Docker — základné príkazy
# Stiahnutie a spustenie kontajnera
$ docker pull nginx:alpine
$ docker run -d -p 80:80 nginx

# Výpis bežiacich kontajnerov
$ docker ps
CONTAINER ID IMAGE STATUS
a1b2c3d4e5f6 nginx Up 2h

# Build vlastného image
$ docker build -t myapp .
$ docker compose up -d
KVM — validácia virtualizácie
# Overenie podpory CPU
$ lscpu | grep -i virtualization
Virtualization: VT-x

# Kontrola KVM modulov
$ lsmod | grep kvm
kvm_intel 380928 0
kvm 1089536 1 kvm_intel

# Validácia QEMU hosta
$ sudo virt-host-validate qemu
QEMU: Checking for hardware virt : PASS
